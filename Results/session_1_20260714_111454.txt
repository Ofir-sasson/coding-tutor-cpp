how to implement my_strcmp

[Tutor  ]
To implement `my_strcmp`, you need to compare two strings character by character until you find a difference or reach the end of one of the strings. Here's how you can do it:

1. **Initialize Pointers**: Start with two pointers, one for each string (`a` and `b`).
2. **Compare Characters**: Loop through both strings, comparing characters at corresponding positions.
3. **Return Result**:
   - If a difference is found, return the result of subtracting the ASCII values of the differing characters.
   - If the end of either string is reached without finding a difference, return 0 if both pointers have reached the null terminator (`'\0'`), indicating that the strings are equal. Otherwise, return the difference based on which pointer has reached the null terminator.

Here's an example implementation:

```c
int my_strcmp(const char* a, const char* b) {
    // Loop through both strings until a difference is found or one string ends
    while (*a != '\0' && *b != '\0') {
        if (*a != *b) {
            return (*a - *b);
        }
        a++;
        b++;
    }

    // If we reach here, either both strings ended at the same time (equal)
    // or one string ended before the other
    return (*a - *b);
}
```

### Explanation:
- **`while (*a != '\0' && *b != '\0')`**: This loop continues as long as neither pointer has reached the null terminator.
- **`if (*a != *b)`**: If characters at the current positions of `a` and `b` are different, return their difference. This will be negative if `*a < *b`, positive if `*a > *b`.
- **`a++` and `b++`**: Move both pointers to the next character.
- **After the loop**: If the loop exits because one string ended before the other, return the difference between the characters at the current positions of `a` and `b`. This will be zero if both strings are equal up to the point where one ends.

This implementation ensures that the function compares strings lexicographically without using any `<string.h>` functions.
